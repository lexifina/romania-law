# Articolul 714
Cazurile speciale
Dacă titlul executoriu emis de un alt organ decât o instanță judecătorească a fost desființat de acel organ sau de un alt organ din afara sistemului instanțelor judecătorești, iar modalitatea restabilirii situației anterioare executării nu este prevăzută de lege ori, deși este prevăzută, nu s-a luat această măsură, ea se va putea obține pe calea unei cereri introduse la instanța prevăzută la art. 713 alin. (3).
