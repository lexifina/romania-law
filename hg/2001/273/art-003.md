# Articolul 3
Copresedintii delegatiilor sectoriale corespunzătoare fiecăruia dintre capitolele de negociere sunt secretarii de stat pentru integrare europeană sau responsabilii, la nivel de conducere, desemnați în acest scop din cadrul celorlalte organe ale administrației publice centrale, pentru capitolele la care instituția respectiva este integratoare.
