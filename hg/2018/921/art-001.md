# Articolul 1
Guvernatorul pentru România în Consiliul Guvernatorilor Băncii Internaționale de Investiții este secretarul de stat din Ministerul Finanțelor Publice, responsabil cu coordonarea relațiilor cu instituțiile financiare internaționale, iar supleantul său este o persoană responsabilă cu coordonarea relațiilor cu instituțiile financiare internaționale, desemnată de ministrul finanțelor publice.
