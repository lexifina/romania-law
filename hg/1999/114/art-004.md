# Articolul 4
(1) Coordonarea Programului național de aderare a României la Uniunea Europeană este asigurata de Departamentul pentru Integrare Europeană.
(2) Programul de îndeplinire a criteriilor politice de aderare este coordonat de Departamentul pentru Integrare Europeană.
(3) Programul de îndeplinire a criteriilor economice de aderare este coordonat de Ministerul Finanțelor.
(4) Programul de adoptare a acquisului comunitar este coordonat de Departamentul pentru Integrare Europeană.
(5) Programul de reforma administrativă este coordonat de Departamentul pentru Reforma Administrației Publice Centrale.
(6) Programul de finanțare este coordonat de Ministerul Finanțelor.
