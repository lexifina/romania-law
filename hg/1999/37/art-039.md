# Articolul 39
(1) Pentru doctoranzii înmatriculați până la data de 31 decembrie 1992, termenul limita pentru depunerea tezelor de doctorat în vederea sustinerii lor publice este data de 31 decembrie 1999 sau o dată decalata corespunzător cu durata intreruperilor aprobate.
(2) Pentru doctoranzii înmatriculați după data de 1 ianuarie 1993, termenul limita pentru susținerea tezei de doctorat este în conformitate cu prevederile prezentei hotărâri.
