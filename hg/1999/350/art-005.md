# Articolul 5
Rata dobânzii obligațiunilor de tezaur cu dobânda denominate în valută ale statului, seriile VAL 1999 - 1C, 2C, 3C, 4C, 5C, 1D, 2D, 3D, 4D și 5D este de:
a) 7,5% pe an pentru obligațiunile în dolari S.U.A., lansate pe o perioadă de 91 de zile;
b) 8,0% pe an pentru obligațiunile în dolari S.U.A., lansate pe o perioadă de 182 de zile;
c) 5,0% pe an pentru obligațiunile în mărci germane, lansate pe o perioadă de 91 de zile;
d) 5,5% pe an pentru obligațiunile în mărci germane, lansate pe o perioadă de 182 de zile și se determina conform formulei:
N x r x z
D = ---------, 365 în care:
D = valoarea dobânzii;
N = valoarea nominală totală a obligațiunilor de tezaur cu dobânda denominate în valută ale statului deținute; r = rata dobânzii; z = numărul de zile pentru care se calculează dobânda (91, respectiv 182 de zile).
