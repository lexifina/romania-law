# Articolul 2
Se aprobă declanșarea procedurilor de expropriere a tuturor imobilelor proprietate privată care constituie coridorul de expropriere situat pe amplasamentul lucrării de utilitate publică de interes național „Perdele forestiere de protecție a drumului național DN 2B, județul Brăila, pozițiile km: 60 + 210 - 60 + 350; 60 + 365 - 61 + 000; 67 + 750 - 69 + 050; 70 + 150 - 72 + 000; 72 + 000 - 72 + 100; 72 + 110 - 74 + 200; 74 + 210 - 75 + 100; 75 + 110 - 75 + 200; 75 + 210 - 76 + 100; 76 + 110 - 77 + 000; 81 + 000 - 81 + 700”, partea stângă, de pe raza localităților Ianca și Traian, județul Brăila, expropriator fiind statul român, reprezentat de Ministerul Mediului, Apelor și Pădurilor, prin Regia Națională a Pădurilor - Romsilva.
