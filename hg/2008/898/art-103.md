# Articolul 103
(1) Episcopul este președintele Consistoriului superior. Dacă acesta nu este disponibil sau locul său este vacant, președinția ședinței este asigurată de curatorul comunității bisericești generale.
(2) Dacă nici acesta nu este disponibil sau locul său este vacant, președinția ședinței este asigurată de episcopul vicar. În caz de alte indisponibilități, în prima ședință a Consistoriului superior președinția este preluată de cel mai în vârstă membru cleric.
(3) În toate celelalte ședințe, președinția este asigurată de locțiitorul curatorului comunității bisericești generale și, în sfârșit, de locțiitorul episcopului vicar.
