# Articolul 28
(1) Orice nava care arboreaza pavilionul român este deservita de un echipaj care asigura operarea navei în condiții de siguranță și de protecție a mediului și îndeplinește alte activități la bordul navei.
(2) Echipajul este format din personal navigant și personal auxiliar, iar componenta acestuia este stabilită conform tipului și destinației navei.
