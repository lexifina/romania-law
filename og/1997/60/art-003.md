# Articolul 3
Persoanele juridice și cele fizice răspund, potrivit legii, de toate efectele nocive ale incendiilor, care decurg din: existenta sau utilizarea construcțiilor, echipamentelor, mijloacelor, utilajelor și instalațiilor tehnologice pe care le dețin sau administrează; de activitatea desfășurată sau în legătură cu aceasta; de produsele pe care le folosesc, le prelucreaza, le furnizează, le transporta, le stocheaza sau le comercializează.
