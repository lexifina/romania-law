# Articolul 5
(1) Orice persoană acuzata sau cercetata pentru săvârșirea unei infracțiuni este prezumată nevinovată atât timp cat nu a fost condamnata printr-o hotărâre penală definitivă și irevocabilă. ...
(2) Respectarea prezumției de nevinovatie este obligatorie în orice program audiovizual. ...
