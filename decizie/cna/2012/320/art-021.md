# Articolul 21
(1)
Furnizorii au obligația să publice, pe pagina web de start a serviciului, la loc vizibil: a)
informațiile, detaliate, clare și actualizate, precizate la art. 48 din Legea audiovizualului; ...
b)
adresa poștală și site-ul CNA. ...
(2)
Furnizorii au obligația să asigure, pe pagina web de start a serviciului, un link către formularul pentru sesizări și reclamații.
