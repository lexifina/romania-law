# Articolul 3
Se aprobă retragerea, la cerere, a autorizației de funcționare pentru asigurări de viață a Societății EUREKO ASIGURĂRI - S.A. și a modificărilor aferente aduse actului constitutiv, conform Hotărârii adunării generale extraordinare a acționarilor din data de 28 aprilie 2014 și Actului adițional din data de 29 aprilie 2014.
