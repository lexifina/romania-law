# Articolul 1
Se aduce la cunoștința publică derularea lucrărilor de înregistrare sistematică, pe sectoare cadastrale, în 8 unități administrativ-teritoriale din județul Giurgiu, după cum urmează:
a) unitatea administrativ-teritorială Bolintin-Vale - sectoarele cadastrale nr. 17, 19, 20, 24, 27, 28, 29, 33, 41, 73, 84, 85, 99;
b) unitatea administrativ-teritorială Găiseni - sectoarele cadastrale nr. 2, 3, 4, 5, 6, 14, 15, 16, 17, 20, 23, 52;
c) unitatea administrativ-teritorială Gogoșari - sectoarele cadastrale nr. 3, 4;
d) unitatea administrativ-teritorială Oinacu - sectorul cadastral nr. 6;
e) unitatea administrativ-teritorială Ulmi - sectoarele cadastrale nr. 9, 10, 11, 12, 14, 20, 26, 28;
f) unitatea administrativ-teritorială Valea Dragului - sectoarele cadastrale nr. 1, 2, 3, 12;
g) unitatea administrativ-teritorială Vărăști - sectoarele cadastrale nr. 18, 19, 20;
h) unitatea administrativ-teritorială Vânătorii Mici - sectoarele cadastrale nr. 2, 12, 15, 42, 48, 54, 58, 62, 64, 65, 70, 72, 78, 79, 80.
