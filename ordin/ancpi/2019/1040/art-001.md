# Articolul 1
Se aduce la cunoștința publică derularea lucrărilor de înregistrare sistematică, pe sectoare cadastrale, în 11 unități administrativ-teritoriale din județul Mureș, după cum urmează:
a) unitatea administrativ-teritorială Acățari - sectoarele cadastrale nr. 1, 3, 38, 39, 40, 41, 42, 43, 44, 50;

c) unitatea administrativ-teritorială Chibed - sectoarele cadastrale nr. 13, 14, 16, 17, 18, 22, 26, 27, 28, 29;
d) unitatea administrativ-teritorială Fântânele - sectoarele cadastrale nr. 8, 11, 16, 17, 18, 19, 21, 25, 26;
e) unitatea administrativ-teritorială Mica - sectoarele cadastrale nr. 3, 4, 5, 14, 19, 27, 28, 58, 80;
f) unitatea administrativ-teritorială Neaua - sectoarele cadastrale nr. 1, 3, 5, 19, 24, 35, 39, 41;
g) unitatea administrativ-teritorială Râciu - sectoarele cadastrale nr. 1, 2, 4, 5, 34, 35, 36, 45, 47, 62, 67, 81, 82, 88, 92, 93, 94, 95, 98, 100, 104, 105, 110, 118, 120, 121, 132, 139, 142, 143, 173;

i) unitatea administrativ-teritorială Sighișoara - sectoarele cadastrale nr. 32, 33, 35, 50, 53, 97, 98;
j) unitatea administrativ-teritorială Stânceni - sectoarele cadastrale nr. 4, 8, 9, 14, 17, 20, 21, 22, 26, 27, 28, 31, 33, 34, 35, 38, 39, 40, 43;
k) unitatea administrativ-teritorială Ungheni - sectorul cadastral nr. 76.
