# Articolul 2
(1) ETRS89 este definit de către Subcomisia Asociației Internaționale de Geodezie (International Association of Geodesy - IAG) pentru Rețeaua de Referință Europeană (European Reference Frame - EUREF) ca fiind identic cu Sistemul de Referință Terestru Internațional (ITRS) la epoca 1989.0, atașat părții stabile a plăcii euroasiatice.
(2) ETRS89 este alcătuit, conform ISO 19111, din datumul geodezic ETRS89, bazat pe elipsoidul GRS80 (Geodetic Reference System 1980 - Sistem de Referință Geodezic 1980) și sistemul de coordonate geodezice elipsoidale.
(3) Elementele definitorii ale ETRS89 sunt prezentate în anexa care face parte integrantă din prezentul ordin.
