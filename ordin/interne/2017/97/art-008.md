# Articolul 8
(1) Fiecare examinator care participă la proba practică se asigură că sistemul tehnic de monitorizare utilizat este funcțional.
(2) Camera audiovideo a sistemului tehnic de monitorizare se instalează, într-un punct fix, în autovehiculul pe care este afișată vizibil mențiunea „EXAMEN”. Aceasta se orientează paralel cu partea carosabilă, astfel încât să surprindă traficul pe direcția de deplasare a autovehiculului.
(3) Examinatorul se asigură că, pe întreaga durată a probei practice, obiectivul camerei audiovideo nu este obturat.
