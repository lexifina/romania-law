# Anexa 3
EMBLEMA DE ONOARE A MINISTERULUI A FACERILOR INTERNE CU ÎNSEMN DE RĂZBOI Emblema de onoare a Ministerului Afacerilor Interne cu însemn de război este similară emblemei de onoare a Ministerului Afacerilor Interne pentru misiuni internaționale, cu precizarea că, pe revers, este scris EMBLEMA DE ONOARE/A/MINISTERULUI AFACERILOR INTERNE/CU/ÎNSEMN DE RĂZBOI, iar extremitățile lamelor celor două spade încrucișate, aurii, broșează atât peste dispozitivul de prindere, cât și pe extremitățile superioare ale frunzelor de lauri aflate în partea cea mai de sus a celor două ramuri.
