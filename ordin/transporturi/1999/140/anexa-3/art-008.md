# Articolul 8
Prin produs feroviar se înțelege orice sistem, subsistem, ansamblu, organ, component sau program de calculator, destinat materialului rulant, caii de rulare, semnalizarii feroviare, alimentarii cu energie electrica, controlului și comenzii circulației feroviare, instalațiilor de mentenanță, sau având legătură cu mai multe din aceste elemente.
