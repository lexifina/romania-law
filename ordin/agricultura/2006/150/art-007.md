# Articolul 7
În baza prevederilor art. 3 alin. (2) din Hotărârea Guvernului nr. 255/2006 privind stabilirea produselor pentru care se eliberează certificate de export și de import și a cuantumului garanțiilor aferente exportului și importului de produse agricole, începând cu 1 martie 2006 inclusiv, operatorii economici care dețin certificate de import în curs de valabilitate, pe baza cantității alocate prin acestea și rămase neefectuată la această dată, vor completa cererea pentru eliberarea certificatului de import conform prevederilor Legii nr. 300/2005, cu modificările ulterioare, și ale Legii nr. 299/2005, cu modificările ulterioare, în care la rubrica nr. 20 "Informații speciale" se înscriu numărul certificatului de import și data eliberării acestuia. Eliberarea certificatului de import se efectuează conform prevederilor Legii nr. 300/2005, cu modificările ulterioare, și ale Legii nr. 299/2005, cu modificările ulterioare.
