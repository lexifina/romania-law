# Articolul 2
(1) Permisul de pescuit recreativ/sportiv este un document, cu regim special, înseriat, a cărui tipărire este asigurată de Agenție.
(2) Permisul de pescuit recreativ/sportiv este nominal, netransmisibil și se eliberează anual.
(3) Modelul permisului de pescuit recreativ/sportiv este prevăzut în anexa nr. 1.
