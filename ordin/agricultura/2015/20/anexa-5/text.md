# Anexa 2
LISTA cuprinzând caracteristicile tehnice ale formularului carnetului de comercializare a produselor din sectorul agricol Carnetul de comercializare a produselor din sectorul agricol se tipărește cu respectarea următoarelor caracteristici tehnice:
a) tipărire pe format A5;
b) carnet cu următoarele caracteristici:
b.1. copertă hârtie offset 80 g/mp; b.2. prima filă exemplar nedetașabil, hârtie albă 80 g/mp, text de culoare neagră; b.3. următoarele cinci file exemplare nedetașabile, hârtie albă 80 g/mp, text la negru, tipărite identic față-verso; b.4. tipar file nedetașabile: fila 1, 2+0; filele 2, 3, 4, 5 și 6, 2+1; b.5. 3 file/exemplar x 40 seturi/carnet (120 file/carnet); b.6. total file interior carnet - 126 de file; b.7. perfor pentru detașarea filelor din carnet; b.8. culori interior 2/verso netipărit; b.9. hârtie interior pentru cele 40 de seturi: hârtie autocopiativă alb/roz/verde; b.10. elemente grafice de securitate: ghioș tipărit pe fiecare filă a carnetului; b.11. seria: se completează cu indicativul județului/municipiului București; - numerator pentru seturi file interior autocopiative: 7 cifre, de la 0000001 la 0010000;
c) text de culoare neagră;
d) carnet capsat cu două capse pe latura de 210 mm.
