# Articolul 2
(1) Modelul Registrului special de evidență a beneficiarilor de sprijin financiar este prevăzut în anexa nr. 1.
(2) Modelul Acordului prealabil pentru finanțare este prevăzut în anexa nr. 2.
(3) Modelul Cererii de plată este prevăzut în anexa nr. 3.
(4) Modelul Situațiilor centralizatoare a beneficiarilor și sumelor aferente cantităților de motorină determinate cu acciză redusă este prevăzut în anexa nr. 4.
