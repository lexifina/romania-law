# Articolul 134
Dacă OTS nu a dispus livrarea creșterii de putere într-un ID sau dacă PDefi din formula prevăzută la Art. 133 - are valoarea zero sau aceasta este nedeterminată, prețul pentru deficit de energie în acest ID este stabilit ca fiind egal cu PIP în intervalul de tranzacționare corespunzător ID respectiv; în cazul în care PIP are valoare negativă sau este zero, prețul pentru deficit de energie în acest ID este stabilit ca fiind egal cu limita minimă de preț a ofertei preț- cantitate pe PE.
