# Articolul 127
ODPE determină veniturile rezultate din echilibrarea sistemului, separat pentru fiecare ID i din luna de livrare, după cum urmează: V_(EchSist,i) = Σ {[q_(i,x)]^Red *[p_(i,x)]^Red} - DV_(Con,i) unde: -
V_(EchSist,i) reprezintă veniturile rezultate din echilibrarea sistemului în ID i;
- [q_(i,x)]^Red reprezintă cantitatea de energie efectiv livrată corespunzătoare tranzacției definitive x pentru furnizarea reducerii de putere în ID i;
- [p_(i,x)]^Red reprezintă prețul tranzacției definitive x pentru furnizarea reducerii de putere în ID i.
