# Articolul 136
Dacă OTS nu a dispus livrarea reducerii de putere într-un ID sau dacă PExci din formula prevăzută la Art. 135 - are valoarea zero sau aceasta este nedeterminată, prețul pentru excedent de energie în acest ID este stabilit ca find egal cu PIP în intervalul de tranzacționare corespunzător ID respectiv; în cazul în care PIP are valoare negativă sau este zero, prețul pentru excedent de energie în acest ID este stabilit ca fiind egal cu limita minimă de preț a ofertei preț- cantitate pe PE.
