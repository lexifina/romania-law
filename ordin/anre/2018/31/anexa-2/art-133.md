# Articolul 133
Dacă OTS a dispus livrarea creșterii de putere într-un ID, prețul pentru deficit de energie în acest ID i este determinat astfel: PDefi = C_(EchSist,i) / Σ[(q_ij)^Cres)] unde: -
PDefi reprezintă prețul pentru deficit de energie în ID i;
-
C_(EchSist,i) reprezintă costurile pentru echilibrarea sistemului în ID i, determinate conform prevederilor Art. 125 -;
- (q_ij)^Cres) reprezintă cantitatea efectiv livrată, corespunzătoare tranzacției definitive pentru furnizarea creșterii de putere în ID i; [q_(i,j)]^Cres este considerată ca valoare pozitivă orară, exprimată în MWh, cu 3 zecimale.
