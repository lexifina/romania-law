# Articolul 114
Dezechilibrul sistemului pe fiecare ID se determină astfel:
a) cantitatea agregată corespunzătoare reducerii de putere care a fost efectiv livrată în acest ID
b) minus cantitatea agregată corespunzătoare creșterii de putere care a fost efectiv livrată în acest ID;
b) minus valoarea schimburilor neplanificate cu toate părțile externe interconectate.
