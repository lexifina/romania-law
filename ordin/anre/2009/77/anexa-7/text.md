# Anexa nr. 7
Anexa 1 la Contractul-cadru ------------------- pentru furnizarea reglementată a gazelor naturale la consumatorii noncasnici ---------------------------------------------------------------------------- Graficul de furnizare a cantităților de gaze naturale contractate (pentru consumatorul al cărui consum anual se încadrează în categoriile B4-B6 sau A2-A5)
```
┌──────────┬─────────────────────┬────────────────────┬───────────┬──────────┐
│ Perioada │Cantitatea lunară*1) │     Cantitatea     │Cantitatea │Cantitatea│
│de livrare│- istoric de consum -│ prognozată*2)/lună │  zilnică  │  orară   │
│  (luna)  │(unități de energie/ │(unități de energie/│ unități de│unități de│
│          │        lună)        │       lună)        │ energie/zi│ energie/h│
├──────────┼─────────────────────┼────────────────────┼───────────┼──────────┤
│          │                     │                    │           │          │
├──────────┼─────────────────────┼────────────────────┼───────────┼──────────┤
│          │                     │                    │           │          │
└──────────┴─────────────────────┴────────────────────┴───────────┴──────────┘
```

-------------- *1) Se completează de către furnizor la semnarea contractului și poate fi acceptată de consumator. *2) Se completează de către consumator și va fi acceptată de furnizor, dacă necesarul de consum al consumatorului este diferit de istoricul de consum, cu o motivare corespunzătoare. NOTE: 1. Defalcarea cantităților lunare pe cantități zilnice/orare se agreează între furnizor și consumator. Părțile pot conveni asupra unei proceduri de transmitere a prognozelor de consum zilnic/săptămânal/lunar. 2. În cazul în care contractul se încheie pe durată nedeterminată, părțile stabilesc anual graficul de furnizare a cantităților de gaze naturale contractate.
