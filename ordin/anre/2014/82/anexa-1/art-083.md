# Articolul 83
Următoarele condiții sunt satisfăcute pentru zona de piețe cuplate: prețul de închidere a pieței în zona de ofertare importatoare este mai mare sau egal cu prețul de închidere a pieței din zona de ofertare exportatoare, iar dacă fluxul de import sau export este mai mic decât capacitatea disponibilă de interconexiune, prețurile de închidere în cele două zone sunt egale.
