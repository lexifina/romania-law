# Articolul 18
(1) Taxa pe valoarea adăugată este considerată eligibilă, dacă sunt îndeplinite simultan următoarele condiții:
a) nu este recuperabilă prin orice alte mijloace prevăzute de legislația națională;
b) este aferentă unor cheltuieli considerate eligibile.
(2) Nu este eligibilă taxa pe valoarea adăugată aferentă costurilor generale de administrație calculate pe baza unei pro rata pentru acei beneficiari care desfășoară operațiuni cu/fără drept de deducere.
