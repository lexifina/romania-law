# Articolul 1
Se acordă acreditarea pentru unitatea de învățământ preuniversitar particular Grădinița cu program prelungit „Zum - Zum”, cu sediul în municipiul București, strada Vespasian nr. 37, sectorul 1, pentru nivelul de învățământ „preșcolar”, limba de predare „română”, program „normal” și program „prelungit”.
