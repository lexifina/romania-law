# Articolul 1
Se acordă acreditarea pentru unitatea de învățământ preuniversitar particular Grădinița cu program normal și program prelungit „Ciufulici”, cu sediul în municipiul Călărași, strada Viitor nr. 84, județul Călărași, pentru nivelul de învățământ „preșcolar”, limba de predare „română”, program „normal” și program „prelungit”.
