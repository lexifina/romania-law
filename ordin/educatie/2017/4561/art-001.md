# Articolul 1
Se acordă acreditarea pentru unitatea de învățământ preuniversitar particular Grădinița cu program prelungit „Angelʾs Academy”, cu sediul în municipiul București, strada Măgura Vulturului nr. 38, sectorul 2, pentru nivelul de învățământ „preșcolar”, limba de predare „română”, program „normal” și program „prelungit”.
