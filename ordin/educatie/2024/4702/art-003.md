# Articolul 3
Personalul didactic și personalul administrativ din unitatea de învățământ preuniversitar particular autorizată Grădinița cu Program Prelungit „Mirabela” din satul Păulești, comuna Păulești, județul Prahova, angajat conform prevederilor legii pentru formațiunile de studiu școlarizate conform dispozițiilor art. 1, se preia la unitatea de învățământ preuniversitar particular acreditată Grădinița cu Program Prelungit „Mirabela” din satul Păulești, comuna Păulești, județul Prahova.
