# Articolul 2
Se aprobă programele școlare pentru clasele a III-a și a IV-a, alternativa educațională Waldorf, cuprinse în anexa nr. 2, care face parte integrantă din prezentul ordin, după cum urmează: Programa școlară pentru disciplina Limba și literatura română; Programa școlară pentru disciplina Limba și literatura română pentru învățământul în limbile minorităților naționale; Programa școlară pentru disciplina Limba și literatura maternă maghiară - versiune în limba maghiară; Programa școlară pentru disciplina Limba și literatura maternă maghiară - traducere în limba română; Programa școlară pentru disciplina Limba modernă 1; Programa școlară pentru disciplina Limba modernă 2; Programa școlară pentru disciplina Limba modernă 1 pentru învățământul în limbile minorităților naționale; Programa școlară pentru disciplina Matematică; Programa școlară pentru disciplina Științe ale naturii; Programa școlară pentru disciplina Cunoștințe despre ținutul natal; Programa școlară pentru disciplina Educație fizică; Programa școlară pentru disciplina Educație plastică; Programa școlară pentru disciplina Desen de forme; Programa școlară pentru disciplina Educație muzicală; Programa școlară pentru disciplina Euritmie; Programa școlară pentru disciplina Jocuri de mișcare; Programa școlară pentru disciplina Abilități practice.
