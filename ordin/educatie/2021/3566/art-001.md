# Articolul 1
Se acordă acreditarea pentru unitatea de învățământ preuniversitar particular Grădinița cu program normal și program prelungit „RIO 2”, cu sediul în municipiul București, strada Stoica Vizitiu nr. 4, sectorul 6, pentru nivelul de învățământ „preșcolar”, program „prelungit”, limba de predare „română”, începând cu anul școlar 2021-2022, conform anexei care face parte integrantă din prezentul ordin.
