# Articolul 1
Se acordă autorizația de funcționare provizorie S.C. Bemindful Kids - S.R.L. din municipiul București pentru unitatea de învățământ preuniversitar particular Grădinița cu program prelungit „Bemindful Kids”, cu sediul în municipiul București, strada Nicolae Florescu nr. 126, sectorul 4, București, pentru nivelul de învățământ „preșcolar”, program „normal” și program „prelungit”, limba de predare „română”, începând cu anul școlar 2021-2022, conform anexei care face parte integrantă din prezentul ordin.
