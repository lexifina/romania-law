# Articolul 1
Se acordă autorizația de funcționare provizorie S.C. Apple Tree Edu - S.R.L. din municipiul București, pentru unitatea de învățământ preuniversitar particular Grădinița cu Program Prelungit „Apple Tree”, cu sediul în municipiul București, strada Măicănești nr. 22, sectorul 1, București, pentru nivelul de învățământ „preșcolar”, program „prelungit”, limba de predare „română”, începând cu anul școlar 2021-2022, conform anexei care face parte integrantă din prezentul ordin.
