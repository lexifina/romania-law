# Articolul 3
Personalul didactic, didactic auxiliar și personalul nedidactic din unitatea de învățământ preuniversitar particular autorizată Grădinița cu Program Normal și Prelungit „Happy Hours” din comuna Berceni, angajat conform prevederilor legii, se preia la unitatea de învățământ preuniversitar particular acreditată Grădinița cu Program Normal și Prelungit „Happy Hours” din comuna Berceni.
