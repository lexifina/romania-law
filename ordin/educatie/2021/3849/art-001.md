# Articolul 1
Se acordă acreditarea pentru unitatea de învățământ preuniversitar particular Grădinița cu program normal și program prelungit „Sfântul Nicolae”, cu sediul în municipiul Curtea de Argeș, Strada Eroilor nr. 10, județul Argeș, pentru nivelul de învățământ „preșcolar”, program „normal” și program „prelungit”, limba de predare „română”, începând cu anul școlar 2021-2022, conform anexei care face parte integrantă din prezentul ordin.
