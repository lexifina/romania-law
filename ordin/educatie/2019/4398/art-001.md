# Articolul 1
Se acordă acreditarea pentru unitatea de învățământ preuniversitar particular Grădinița Adventistă cu program prelungit „Albinuța”, cu sediul în comuna Halmeu, Strada Libertății nr. 79, județul Satu Mare, pentru nivelul de învățământ „preșcolar”, cu program „prelungit”, limba de predare „română”, începând cu anul școlar 2019 - 2020, conform anexei care face parte integrantă din prezentul ordin.
