# Articolul 1
Se acordă acreditarea pentru unitatea de învățământ preuniversitar particular Grădinița cu program prelungit „Gărgărița”, cu sediul în comuna Mărăcineni, Strada Principală nr. 8, județul Buzău, pentru nivelul de învățământ „preșcolar”, limba de predare „română”, program „normal” și program „prelungit”, începând cu anul școlar 2019-2020, conform anexei care face parte integrantă din prezentul ordin.
