# Articolul 1
Se acordă acreditarea pentru unitatea de învățământ preuniversitar particular Grădinița cu program prelungit „Emanuel”, cu sediul în municipiul Reghin, Piața Mică nr. 1-3, județul Mureș, pentru nivelul de învățământ „preșcolar”, limba de predare „română”, program „normal” și program „prelungit”, începând cu anul școlar 2019-2020, conform anexei care face parte integrantă din prezentul ordin.
