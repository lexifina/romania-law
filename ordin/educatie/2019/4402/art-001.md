# Articolul 1
Se acordă acreditarea pentru unitatea de învățământ preuniversitar particular Grădinița cu program prelungit „Jovial” din municipiul Adjud, cu sediul în municipiul Adjud, strada Vasile Alecsandri FN, județul Vrancea, pentru nivelul de învățământ „preșcolar”, cu program „normal” și program „prelungit”, limba de predare „română”, începând cu anul școlar 2019-2020, conform anexei care face parte integrantă din prezentul ordin.
