# Articolul 1
Se acordă acreditarea pentru unitatea de învățământ preuniversitar particular Grădinița cu program normal „Tudor”, cu sediul în municipiul Sighetu Marmației, strada Mihai Eminescu nr. 13, județul Maramureș, pentru nivelul de învățământ „preșcolar”, cu program „normal”, limba de predare „română”, începând cu anul școlar 2019-2020, conform anexei care face parte integrantă din prezentul ordin.
