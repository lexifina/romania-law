# Articolul 1
(1) Se acordă autorizația de funcționare provizorie unității de învățământ preuniversitar particular Grădinița cu program normal „Hello Teddy One”, cu sediul în Str. Bucovinei nr. 2F, municipiul Constanța, județul Constanța, respectiv sediul din Str. Limanului nr. 7, municipiul Constanța, județul Constanța, pentru nivelul de învățământ „preșcolar”, forma de învățământ „program prelungit”, limba de predare „română”, începând cu anul școlar 2025-2026.
(2) Începând cu anul școlar 2025-2026, Grădinița cu program normal „Hello Teddy One” din municipiul Constanța, județul Constanța, se va numi Grădinița cu program prelungit „Hello Teddy One” din municipiul Constanța, județul Constanța.
