# Articolul 1
(1) Se acordă autorizația de funcționare provizorie Universității de Vest din Timișoara, cu sediul în bd. Vasile Pârvan nr. 4, municipiul Timișoara, județul Timiș, pentru unitatea de învățământ preuniversitar de stat Grădinița cu Program Prelungit „Smart Start UVT”, componentă organizatorică fără personalitate juridică a Universității de Vest din Timișoara, cu sediul în Piața Sf. Petru nr. 5, municipiul Timișoara, județul Timiș, pentru nivelul de învățământ „preșcolar”, limba de predare „română”, forma de învățământ „program prelungit”, începând cu anul școlar 2025-2026.
(2) Prezentul ordin reprezintă actul de înființare a unității de învățământ preuniversitar de stat Grădinița cu Program Prelungit „Smart Start UVT”, cu sediul în Piața Sf. Petru nr. 5, municipiul Timișoara, județul Timiș.
