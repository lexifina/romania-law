# Articolul 3
Personalul didactic și personalul nedidactic din unitatea de învățământ preuniversitar particular autorizată să funcționeze provizoriu Grădinița cu program normal și program prelungit „Springfield” din municipiul București, sectorul 2, angajat conform prevederilor legii pentru formațiunile de studiu școlarizate conform art. 1, se preia la unitatea de învățământ preuniversitar particular acreditată Grădinița cu program normal și program prelungit „Springfield” din municipiul București, sectorul 2.
