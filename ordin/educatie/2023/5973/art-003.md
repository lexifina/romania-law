# Articolul 3
Personalul didactic și nedidactic din unitatea de învățământ preuniversitar particular autorizată să funcționeze provizoriu Grădinița cu Program Normal și Prelungit „Veverița Jucăușă” din municipiul București, sectorul 2, angajat conform prevederilor legii pentru formațiunile de studiu școlarizate conform prevederilor art. 1, se preia la unitatea de învățământ preuniversitar particular acreditată Grădinița cu Program Normal și Prelungit „Veverița Jucăușă” din municipiul București, sectorul 2.
