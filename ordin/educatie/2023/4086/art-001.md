# Articolul 1
Se acordă autorizația de funcționare provizorie Asociației „Zori Kids” pentru unitatea de învățământ preuniversitar particular Grădinița cu Program Normal și Program Prelungit „Zori” din Str. Pandurilor nr. 32, municipiul Reghin, județul Mureș, pentru nivelul de învățământ „preșcolar”, limba de predare „română”, forma de învățământ program „normal” și program „prelungit”, începând cu anul școlar 2023-2024, conform anexei care face parte integrantă din prezentul ordin.
