# Articolul 3
Personalul didactic și personalul nedidactic din unitatea de învățământ preuniversitar particular autorizată Grădinița cu program prelungit „Sfânta Tatiana” din municipiul Craiova, județul Dolj, angajat conform prevederilor legii, se preia la unitatea de învățământ preuniversitar particular acreditată Grădinița cu program prelungit „Sfânta Tatiana” din municipiul Craiova, județul Dolj.
