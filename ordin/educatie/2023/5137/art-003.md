# Articolul 3
Personalul didactic și personalul nedidactic din unitatea de învățământ preuniversitar particular Grădinița cu program normal și program prelungit „Kluge Kinder” din municipiul București, sectorul 1, angajat conform prevederilor legii, se preia la unitatea de învățământ preuniversitar particular acreditată Grădinița cu program normal și program prelungit „Kluge Kinder” din municipiul București, sectorul 1.
