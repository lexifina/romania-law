# Articolul 3
Personalul didactic și personalul nedidactic din unitatea de învățământ preuniversitar particular Grădinița cu Program Prelungit „Tărâmul Zânelor” din municipiul Sibiu, județul Sibiu, angajat conform prevederilor legii, se preia la unitatea de învățământ preuniversitar particular acreditată Grădinița cu Program Prelungit „Tărâmul Zânelor” din municipiul Sibiu, județul Sibiu.
