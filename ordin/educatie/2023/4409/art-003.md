# Articolul 3
Personalul didactic și personalul nedidactic din unitatea de învățământ preuniversitar particular autorizată Grădinița cu Program Prelungit „Sweet Dreams Kindergarten” din municipiul Bacău, județul Bacău, angajat conform prevederilor legii, se preia la unitatea de învățământ preuniversitar particular acreditată Grădinița cu Program Prelungit „Sweet Dreams Kindergarten” din municipiul Bacău, județul Bacău.
