# Articolul 1
(1) Se acordă autorizația de funcționare provizorie unității de învățământ preuniversitar de stat Școala Gimnazială „Platon Mocanu” din comuna Drajna, județul Prahova, pentru structura arondată Grădinița cu program normal, cu sediul în str. Radu Șerban Voevod nr. 19, comuna Drajna, județul Prahova, pentru nivelul de învățământ „preșcolar”, limba de predare „română”, forma de învățământ „program prelungit”, începând cu anul școlar 2023-2024.
(2) Formațiunile de studiu de nivel „preșcolar”, limba de predare „română”, forma de învățământ „program prelungit” se școlarizează în cadrul Grădiniței cu program normal din comuna Drajna, județul Prahova, structură arondată unității de învățământ preuniversitar de stat Școala Gimnazială „Platon Mocanu” din comuna Drajna, județul Prahova.
