# Articolul 3
Personalul didactic și personalul nedidactic din unitatea de învățământ preuniversitar particular Grădinița cu program prelungit „Sfântul Dimitrie” din municipiul Sibiu, județul Sibiu, angajat conform prevederilor legii, se preia la unitatea de învățământ preuniversitar particular acreditată Grădinița cu program prelungit „Sfântul Dimitrie” din municipiul Sibiu, județul Sibiu.
