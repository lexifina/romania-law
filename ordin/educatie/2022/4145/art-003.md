# Articolul 3
Personalul didactic, didactic auxiliar și personalul nedidactic din unitatea de învățământ preuniversitar particular autorizată Grădinița cu Program Normal „MINI ME” din municipiul București, angajat conform prevederilor legii, se preia la unitatea de învățământ preuniversitar particular acreditată Grădinița cu Program Normal „MINI ME” din municipiul București.
