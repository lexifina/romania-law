# Articolul 1
Se acordă acreditarea pentru unitatea de învățământ preuniversitar particular Grădinița cu program normal și program prelungit „Zuppy”, cu sediul în municipiul București, strada Oteșani nr. 69, sectorul 2, pentru nivelul de învățământ „preșcolar”, program „normal” și program „prelungit”, limba de predare „română”, începând cu anul școlar 2022-2023, conform anexei care face parte integrantă din prezentul ordin.
