# Articolul 1
Se acordă autorizația de funcționare provizorie S.C. Odyssey Edu - S.R.L. din orașul Voluntari pentru unitatea de învățământ preuniversitar particular Grădinița cu program normal și program prelungit „Odyssey Kindergarten”, cu sediul în orașul Voluntari, strada Vlad Țepeș nr. 14, județul Ilfov, pentru nivelul de învățământ „preșcolar”, program „normal” și program „prelungit”, limba de predare „română”, începând cu anul școlar 2022-2023, conform anexei care face parte integrantă din prezentul ordin.
