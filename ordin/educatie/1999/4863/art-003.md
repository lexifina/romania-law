# Articolul 3
Media la susținerea lucrării metodico-științifice se calculează conform formulei:
Media la susținere = nota acordată de președinte + nota acordată de inspector + media aritmetică a notelor acordate de coordonator (recenzie + susținere)
3
Media la inspecția specială se calculează conform formulei:
Media la inspecție = suma notelor acordate de membrii comisiei
3
Media generală se calculează conform formulei:
Media generală = media la susținere + media la inspecție
2
În ceea ce privește notele și mediile minime de promovare a probelor, rămân valabile prevederile Metodologiei formării continue a personalului didactic din învățământul preuniversitar, aprobată prin Ordinul ministrului educației naționale nr. 3.770/1998.
