# Articolul 20
(1) Evaluarea planurilor-cadru se va face după un set de criterii, care se referă la fundamentarea teoretico-metodologică, relevanță, funcționalitate și fezabilitate.
(2) Setul de criterii este stabilit de ISE și este transmis grupurilor de lucru, anterior procesului de elaborare a planurilor-cadru.
(3) Setul de criterii menționat la alin. (2) se completează, în cazul învățământului profesional și tehnic, cu criterii specifice, elaborate de CNDIPT.
