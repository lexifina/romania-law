# Articolul 32
Dacă biroul vamal de import acceptă cererea de modificare, se creează o nouă versiune a declarației, respectiv cea modificată care păstrează MRN-ul, data acceptării declarației inițiale și starea „Liber de vamă”. Starea cererii de modificare în aplicația SNI este „Acceptată” și cea a versiunii inițiale a declarației la care se referă este „Modificată după liber de vamă”.
