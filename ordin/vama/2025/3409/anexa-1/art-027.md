# Articolul 27
(1) Autorizația pentru vămuirea centralizată cu implicarea mai multor state membre se eliberează de Autoritatea Vamală Română în cazul în care biroul vamal responsabil de locul în care solicitantul este stabilit, respectiv biroul vamal de supraveghere, este situat pe teritoriul României.
(2) În cazul în care biroul vamal la care sunt prezentate mărfurile, respectiv biroul vamal de prezentare, este situat pe teritoriul României, procedura de consultare este asigurată de Autoritatea Vamală Română.
