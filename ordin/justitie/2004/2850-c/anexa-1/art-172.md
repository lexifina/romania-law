# Articolul 172
(1) Personalul auxiliar de specialitate este format din grefieri șefi cabinet, grefieri șefi secție, grefieri șefi serviciu, grefieri, grefieri-dactilografi, arhivari-registratori și agenți procedurali.
(2) Personalul auxiliar de specialitate este subordonat ierarhic conducerii compartimentelor de activitate din care face parte.
