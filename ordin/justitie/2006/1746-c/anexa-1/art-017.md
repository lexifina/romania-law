# Articolul 17
(1) Fiecare probă de concurs se notează cu note de la 0 la 10. Nu se acordă punct din oficiu.
(2) Corectarea lucrărilor scrise de verificare a cunoștințelor teoretice și aprecierea notei pentru proba practică și pentru interviu se fac pe baza unui punctaj stabilit de toți membrii comisiei de concurs.
(3) Baremul de corectare corespunzător probei scrise și celei practice, precum și modul de notare al etapelor interviului se afișează pe ușa fiecărei săli de concurs și pe pagina web a Ministerului Justiției după încheierea fiecărei probe de concurs.
(4) Notele acordate la fiecare probă de concurs se trec în litere și în cifre în borderoul de notare, care este semnat pe fiecare filă de membrii comisiei de concurs.
(5) Nota finală a fiecărei probe de concurs este media aritmetică a notelor acordate de fiecare membru al comisiei de concurs.
(6) Nota finală a concursului este media ponderată a probelor de concurs. Ea este stabilită de membrii comisiei de concurs și se afișează la sediul Ministerului Justiției și pe pagina web a instituției înainte de desfășurarea primei probe a concursului.
(7) Media ponderată se calculează după cum urmează:
N = A x X + B x Y + C x Z, unde: N = nota finală a concursului; A = nota finală acordată probei scrise; B = nota finală acordată probei practice; C = nota finală a interviului; X = ponderea acordată probei scrise (se exprimă în procente); Y = ponderea acordată probei practice (se exprimă în procente); Z = ponderea acordată interviului (se exprimă în procente).
