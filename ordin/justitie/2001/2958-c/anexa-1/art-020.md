# Articolul 20
(1) Rezultatul probei orale este media aritmetica a notelor acordate de către cei 4 examinatori.
(2) Notarea comisiei la proba orala este definitivă.
(3) Media generală a examenului este rezultatul mediei aritmetice între media obținută la lucrarea scrisă și media obținută la proba orala.
