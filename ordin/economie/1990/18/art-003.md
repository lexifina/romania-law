# Articolul 3
Cererile de autorizații de import și, respectiv, de export se întocmesc pe formulare tipizate, conform anexelor nr. 1 și 2, care fac parte integrantă din prezentul ordin. Cererile de autorizații de import și, respectiv, de export se semnează de împuternicitul persoanei juridice solicitante și, respectiv, de persoana fizica solicitanta, care răspund de exactitatea datelor înscrise în aceste cereri.
