# Articolul 16
Operațiunile de import cu finanțare din credite externe, acordate de guverne sau organisme financiare internaționale, operațiunile de import în cadrul acordurilor de cliring, barter și cooperare, precum și operațiunile de import în cadrul creanțelor externe se realizează pe bază de licență de import eliberate de Ministerul Industriei și Comerțului, cu avizul Ministerului Finanțelor.
