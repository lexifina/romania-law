# Articolul II
În cuprinsul ordinului următoarele sintagme se înlocuiesc după cum urmează:
- "verificarea CS a unității de produs" se înlocuiește cu "verificare EEC";
- "certificat de verificare CS" și "certificatul verificării CS" se înlocuiește cu "certificat de verificare EEC";
- "butelie tip-CS" se înlocuiește cu "butelie tip-EEC";
- "aprobare de model CS" se înlocuiește cu "aprobare de model EEC";
- "certificat pentru aprobare de model CS" se înlocuiește cu "certificat pentru aprobare de model EEC";
- "examinare CS a modelului" se înlocuiește cu "examinare EEC a modelului".
