# Articolul 48
Dimensionarea blocului operator, respectiv determinarea numărului necesar de sali de operație, se face prin raportare la numărul de paturi din secțiile și compartimentele cu profil chirurgical care îl utilizează. ● O sala de operație pentru 30-35 de paturi chirurgicale ● O sala de operație pentru 25 de paturi pentru specialități chirurgicale (transplant, arsi).
