# Articolul 2
(1) Lista zonelor cu transmitere comunitară extinsă (zona roșie) și a celor afectate (zona galbenă) este disponibilă pe site-ul www.insp.gov.ro/cnscbt și se actualizează ori de câte ori este nevoie.
(2) Definiția de caz pentru infecția COVID-19 este postată la adresa www.insp.gov.ro/cnscbt și se actualizează ori de câte ori este nevoie.
