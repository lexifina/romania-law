# Anexa nr. 2 la norme
STANDARDE TEHNICE MINIME pentru monitoare de diagnostic radiologic, inclusiv teleradiologie
Caracteristica Valoarea minimă
A. Se aplică pentru radiografie.
Rezoluție (megapixeli - MP) 2048 x 1536 (3MP)
Pitch maxim pixel 0,21 mm
Orientare Landscape/Portret
Calibrare DICOM GSDF < 10%
Luminanță (cel puțin - min./max.) 1/350 cd/m^2
B. Se aplică pentru mamografie.
Rezoluție (megapixeli - MP) 2560 x 2048 (5MP)
Pitch maxim pixel 0,17 mm
Orientare Portret
Calibrare DICOM GSDF < 10% strict
Luminanță (cel puțin - min./max.) 1/400 cd/m^2
C. Se aplică pentru CT, IRM, ecografie, medicină nucleară.
Rezoluție (megapixeli - MP) 1600 x 1200 (2MP)
Pitch maxim pixel 0,27 mm
Orientare Landscape/Portret
Calibrare DICOM GSDF < 10%
Luminanță (cel puțin - min./max.) 1/350 cd/m^2
