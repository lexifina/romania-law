# Articolul 4
În situația în care în interiorul carnetului de concedii medicale există formulare greșit tipărite, incomplete sau completate greșit de către medic, se va scrie "Anulat" pe formular și acesta nu va fi decupat din carnet. Aceste file vor fi pliate, rămânând în carnet. Pe verso-ul cotorului ultimei file a carnetului de certificate medicale se va preciza: "Acest carnet conține..... file (în cifre și în litere) de la numărul.... la numărul.... și.... file anulate."
