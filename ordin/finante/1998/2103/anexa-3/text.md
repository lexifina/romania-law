# Anexa 3
1. Denumire: Declarație de înregistrare fiscală pentru instituțiile publice
2. Cod: 14.13.01.12
3. Format: A4/t2 x 2
4. Caracteristici de tipărire: file duble
5. Se difuzează: gratuit
6. Se utilizează la: atribuirea codului fiscal unic și eliberarea certificatului de înregistrare fiscală
7. Se întocmește in: 2 exemplare de: instituțiile publice
8. Circula: - originalul - la organul fiscal
- copia - la instituția publica
9. Se arhivează: la dosarul fiscal al instituției publice

MF cod 14.13.01.12
Format A4/t2x2
Tipărit la R.A. "Imprimeria Națională"
INSTRUCȚIUNI DE COMPLETARE A DECLARAȚIEI DE ÎNREGISTRARE
PENTRU INSTITUȚII PUBLICE
Formularul se completează la mașina de scris sau la echipamente similare.
CAPITOLUL 1 - FELUL DECLARAȚIEI
Se marchează cu "X" unul din punctele 1.1, 1.2, 1.3, 1.4 după caz.
O declarație de tip 1.2 se completează când se modifica una din datele din capitolele 2 la 5 inclusiv.
In cazul încetării activității se completează declarație de tip 1.4 capitolele 2 și 6.
În cazul fuzionării, instituția care încetează a exista completează o declarație de tip 1.3.
CAPITOLUL 2 - DATE DE IDENTIFICARE A INSTITUȚIEI 2.1 - Se completează obligatoriu pentru declarațiile de tip 1.2, 1.3, 1.4.
Se completează obligatoriu de către toți declarantii punctele 2.2 la 2.5 și 2.7. 2.6 - Se completează dacă exista telefon sau fax.
CAPITOLUL 3 - SECTORUL DE ACTIVITATE
Se marchează cu "X" unul din sectoarele de activitate.
CAPITOLUL 4 - SISTEMUL DE FINANȚARE
Se marchează cu "X" unul dintre sisteme.
CAPITOLUL 5 - ORGAN TUTELAR 5.2 - Se completează codul județului. 5.3 - Se completează codul primăriilor atribuit pe plan local de DGFPCFS, de la 001 la 999.
CAPITOLUL 7
Se completează numai în cazul unei declarații de tip 1.4.
TALON 2
DENUMIREA ORGANULUI FISCAL este denumirea unității fiscale la care este arondată instituția.
NUMĂR DE ÎNREGISTRARE este numărul de înregistrare al declarației, unic la nivel de an în cadrul unei unități fiscale.
MARCA este codul persoanei care a verificat și înregistrat declarația.
