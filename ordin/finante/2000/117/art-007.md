# Articolul 7
Rata dobânzii obligațiunilor de tezaur cu dobânda, denominate în valută, ale statului, seriile VAL 2000 PF1, VAL 2000 PF2 și VAL 2001 PF3, este de: ● 7,0 % pe an pentru obligațiunile în dolari S.U.A. lansate pe o perioadă de 91 de zile; ● 7,5 % pe an pentru obligațiunile în dolari S.U.A. lansate pe o perioadă de 182 de zile; ● 9,0 % pe an pentru obligațiunile în dolari S.U.A. lansate pe o perioadă de 366 de zile; și se determina conform formulei:
N x r x z D = ---------, 366 în care: D = valoarea dobânzii; N = valoarea nominală totală a obligațiunilor de tezaur cu dobânda, denominate în valută, ale statului, deținute; r = rata dobânzii; z = numărul de zile pentru care se calculează dobânda (91, 182, respectiv 366 de zile).
