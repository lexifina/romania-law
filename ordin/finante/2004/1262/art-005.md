# Articolul 5
Rata dobânzii Dobânda aferentă certificatelor de trezorerie cu dobândă pentru populație este de 14,5% pe an, pentru o perioadă de subscriere de 90 de zile calendaristice, calculată după formula: D = (VN x 14,5 x 90)/(360 x 100), în care: D = suma dobânzii; VN = valoarea nominală a certificatului de trezorerie.
