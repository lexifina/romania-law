# Articolul 3
(1) Cererea este însoțită de următoarele documente:
a) contractul/comanda în baza căruia/căreia se derulează operațiunile (original și copie) și/sau factură, alte documente comerciale justificative;
b) declarația angajament întocmită de titularul operațiunii, prin care se obligă să achite drepturile de import în cazul în care operațiunea nu este finalizată în termenul stabilit de autoritatea vamală. Modelul declarației angajament este prevăzut în anexa nr. 2;
c) formularul ce conține cuantumul drepturilor de import, al cărui model este prevăzut în anexa nr. 3.
(2) Declarația angajament se semnează de reprezentantul legal al titularului operațiunii, iar formularul ce conține cuantumul drepturilor de import se semnează de acesta și de responsabilul financiar.
