# Hotărârea CNCD nr. 480/2016: refuzul examinării petentei la o materie de învățământ universitar la modul oral și nu scris. Petenta este suferindă de un handicap grav vizual, care nu-i permite un scris ușor descifrabil. Petenta prin adresa înregistraă sub nr.3861.21.06.2016, solicită Colegiului director, clasarea petiției ca urmare a stingerii litigiului cu partea reclamată.
