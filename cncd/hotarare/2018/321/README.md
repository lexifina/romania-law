# Hotărârea CNCD nr. 321/2018: discriminarea fiicei petentului privind asistarea la ora de religie, motiv pentru care tatăl acesteia a cerut explicații atât conducerii Școlii, cât și cadrului didactic în calitate de învățător al fiicei petentului. Petentul susține faptul că r2 nu a permis petentului ca în pauza dintre ore să comunice cu fiica sa, și consideră că se aplică un tratament diferențiat părinților divorțați față de cei nedivorțați.
