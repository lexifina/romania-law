# Hotărârea CNCD nr. 629/2019: petentul consideră că prin emiterea OUG 79/2017 pentru modificarea și completarea legii nr.227/2015 privind Codul Fiscal și respectiv a Legii nr.153/2017 privind salarizarea personalului plătit din fonduri publice au fost discriminați membrii de sindicat și solicită acordarea de despăgubiri si restabilirea situației anterioare discriminării, precum și obligarea celor două părți - Guvernul României și Parlamentul României, să publice, în mass-media, un rezumat al hotărârii prin care se constatată săvârșirea discriminării, precum și toate măsurile necesare pentru înlăturarea consecințelor acestor fapte.
