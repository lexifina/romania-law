# Articolul 23
Șeful punctului de control este ofițer activ, desemnat de Ministerul de Interne. Acesta coordonează și răspunde de întreaga activitate din punctul de control, potrivit legii. Șeful punctului de control verifica și ia măsurile legale corespunzătoare pentru îndeplinirea corecta de către personalul din punctul de control a îndatoririlor de serviciu.
