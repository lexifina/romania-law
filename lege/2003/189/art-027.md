# Articolul 27
Rolul Ministerului Justiției și Libertăților Cetățenești
(1) Ministerul Justiției și Libertăților Cetățenești este autoritatea centrală care transmite ministerelor de justiție din alte state, la cererea acestora, informații privind dreptul intern în materie civilă și comercială, precum și în domeniul procedurii civile și comerciale și al organizării judiciare, pentru cazuri judiciare determinate.
(2) Totodată Ministerul Justiției și Libertăților Cetățenești este autoritatea centrală care solicită ministerelor de justiție din alte state informații de felul celor menționate la alin.
