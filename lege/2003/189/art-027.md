# Articolul 27
(1) Ministerul Justiției este autoritatea centrala care transmite ministerelor de justiție din alte state, la cererea acestora, informații privind dreptul intern în materie civila și comerciala, precum și în domeniul procedurii civile și comerciale și al organizarii judiciare, pentru cazuri judiciare determinate.
(2) Totodata Ministerul Justiției este autoritatea centrala care solicită ministerelor de justiție din alte state informații de felul celor menționate la alin. (1), la cererea instanțelor judecătorești române, pentru cazuri judiciare determinate.
