# Articolul 20
Deținătorul unui cec transmisibil prin gir este socotit legitim, dacă justifica dreptul sau printr-o serie neîntrerupta de giruri chiar dacă ultimul gir este în alb. Girurile șterse se socotesc în aceasta privința nescrise. Dacă un gir în alb este urmat de un alt gir, semnatarul acestuia este socotit ca a dobîndit cecul prin gir în alb.
