# Articolul 27
Avalul se da pe cec sau pe adaos. El se exprima prin cuvintele: "pentru aval", sau orice alta forma echivalenta; el este semnat de avalist.
El este socotit ca rezultă din simpla semnatura a avalistului pusă pe fața cecului, afară numai dacă semnatura este a tragatorului.
Avalul trebuie să arate pentru cine este dat. În lipsa acestei arătări el se socotește dat pentru tragator.
