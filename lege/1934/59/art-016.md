# Articolul 16
Girul trebuie să fie necondiționat. Orice condițiune la care este supus se socotește nescrisa.
Girul parțial este nul.
Este de asemenea nul girul trasului.
Girul "la purtător" este echivalent unui gir în alb.
Girul în folosul trasului are valoarea unei chitanțe, în afară de cazul cînd trasul are mai multe stabilimente și dacă girul este făcut în folosul unui stabiliment, altul decât acela asupra căruia cecul a fost tras.
