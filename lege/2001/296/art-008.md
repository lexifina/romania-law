# Articolul 8
Dubla incriminare
(1) Extrădarea poate fi admisă numai dacă fapta pentru care este invinuita sau a fost condamnata persoana a carei extrădare se cere este prevăzută ca infracțiune atât de legea statului solicitant, cat și de legea statului solicitat.
(2) Diferențele existente între calificarea juridică și denumirea date aceleiași infracțiuni de legile celor două state nu prezintă relevanta, dacă prin convenție internationala sau, în lipsa acesteia, prin declarație de reciprocitate nu se prevede altfel.
