# Proiect de lege L9/2019

Proiect / draft — not law. This text was never in force unless and until adopted; see the act it became.

Became: Legea nr. 90/2019 (`legea-90-2019`).

Proiect de lege pentru aprobarea Ordonanţei de urgenţã a Guvernului nr.112/2018 privind accesibilitatea site-urilor web şi a aplicaţiilor mobile ale organismelor din sectorul public

Initiator: Guvernul României.
