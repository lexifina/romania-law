# Articolul 13
Se desemnează Innovation Norway ca operator de program pentru următoarele domenii de finanțare: Sectorul maritim din Mecanismul financiar SEE 2009-2014, Inovare în industria verde din Mecanismul financiar norvegian 2009-2014 și Muncă decentă și dialog tripartit din Mecanismul financiar norvegian 2009-2014.
