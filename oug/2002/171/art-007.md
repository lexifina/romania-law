# Articolul 7
Societatea Comercială "Melana IV" - S.A. este condusă de adunarea generală a acționarilor și este administrată de consiliul de administrație. Adunarea generală a acționarilor este formată din 3 membri numiți prin ordin al ministrului industriei și resurselor, iar consiliul de administrație este format din 5 membri numiți de adunarea generală a acționarilor.
