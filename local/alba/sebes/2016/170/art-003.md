# Articolul 3
— Prezenta hotarare poate fi atacata de catre persoanele indreptatite,in termenul și in condițiile prevazute de Legea nr.554/2004 privind contenciosul administrativ,cu modificarile și completarile ulterioare.
Prezenta hotarare va fi afisata,se va publica in revista primariei și se comunica :
Instituției Prefectului Județ Alba ;
Primarului Municipiului Sebes ;
Viceprimarului Municipiului Sebes ;
Arhitectului Șef ;
Serviciul Patrimoniu,Transport și Registru Agricol ;
Direcția economica ;
Biroul Executari Silite și Control Fiscal
Biroul Buget,Finanțe,Contabilitate și Salarizare ;
Biroul Colectare Creanțe Bugetare ;
Compartimentul Relații Publice și Comunicare.
Sebeș la 30.08.2016
