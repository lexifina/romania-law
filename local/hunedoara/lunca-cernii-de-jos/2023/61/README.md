# Hotărârea Consiliului Local al Comunei Lunca Cernii de Jos nr. 61/2023 Privind modificarea și completarea art. 1 alin. (2) și alin. (3) şi alin. (4) din Legea nr. 227/2015 privind Codul fiscal, cu modificările şi completările ulterioare
