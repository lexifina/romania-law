FIȘA POSTULUI
Nr. 1
┌────────────────────────────────────────────────────────────────────────────┐
│Informații generale privind postul
│
│1. Denumirea postului: Director
│
│2. Nivelul postului: funcție publică de conducere
│
│3. Scopul principal al postului: asigură managementul Arhivelor Naționale
│
│prin planificarea, organizarea, îndrumarea, evaluarea și controlul întregii │
│activități a instituției; coordonează elaborarea programelor, politicilor și│
│strategiilor privind managementul instituției.
│
│
│
│Condiții specifice pentru ocuparea postului
│
│1. Studii de specialitate: studii universitare de licență absolvite cu
│
│diplomă, respectiv studii superioare de lungă durată, absolvite cu diplomă │
│de licență sau echivalentă în unul dintre domeniile de licență: istorie
│
│(specializarea: istorie/arhivistică), drept, științe administrative
│
│(specializarea: administrație publică/administrație europeană), științe ale │
│comunicării (specializarea: comunicare și relații publice/științe ale
│
│informării și documentării), sociologie, (specializarea: sociologie/resurse │
│umane), relații internaționale și studii europene, management, filologie,
│
│filozofie, studii culturale.
│
│2. Perfecționări (specializări): studii de masterat sau postuniversitare în │
│domeniul administrației publice, management ori în specialitatea studiilor │
│necesare exercitării funcției publice.
│
│3. Cunoștințe de operare/programare pe calculator (necesitate și nivel):
│
│operare Windows, Internet - nivel bine.
│
│4. Limbi străine (necesitate și nivel de cunoaștere): cel puțin o limbă
│
│străină de circulație internațională; nivelul de cunoaștere pentru citit/
│
│scris/vorbit: bine.
│
│5. Abilități, calități și aptitudini necesare:
│
│- abilități de comunicare;
│
│- capacitate de analiză de analiză și sinteză;
│
│- capacitate de implementare;
│
│- capacitate de a rezolva eficient problemele;
│
│- capacitate de asumare a responsabilităților;
│
│- capacitate de perfecționare și de valorificare a experienței dobândite;
│
│- creativitate și spirit de inițiativă;
│
│- capacitate de planificare și de a acționa strategic;
│
│- competență în gestionarea resurselor alocate.
│
│6. Cerințe specifice:
│
│- autorizație de acces la informații din clasa secret de stat, nivel strict │
│secret de importanță deosebită;
│
│- activitate cu o dinamică deosebită, ce necesită activități intelectuale
│
│intense, de mare complexitate, presupunând un nivel ridicat de atenție și
│
│opțiuni multiple, ale căror efecte sunt de importanță maximă pentru
│
│activitatea instituției;
│
│- schimbări frecvente și imprevizibile de program, care presupun rezistență │
│la stres;
│
│- deplasări frecvente.
│
│7. Competența managerială (cunoștințe de management, calități și aptitudini │
│manageriale):
│
│- să posede și să aplice cunoștințe de management modern;
│
│- capacitate de a organiza, de a conduce, de a coordona și de a controla
│
│activitatea din domeniile de competență;
│
│- capacitate de a obține cele mai bune rezultate;
│
│- capacitate de a lua decizii și de a evalua impactul acestora;
│
│- abilități de mediere și de negociere;
│
│- abilități în gestionarea resurselor umane;
│
│- obiectivitate în apreciere.
│
│
│
│Atribuțiile postului
│
│
│
│1. Stabilește obiectivele Arhivelor Naționale în raport cu misiunea
│
│instituției și monitorizează realizarea acestora;
│
│2. Coordonează elaborarea planului strategic al Arhivelor Naționale și
│
│stabilește măsuri de implementare a acestuia;
│
│3. Coordonează elaborarea planului unic de activitate al Arhivelor Naționale│
│și urmărește realizarea indicatorilor propuși;
│
│4. Aprobă planurile anuale de activitate ale structurilor din sistemul
│
│Arhivelor Naționale;
│
│5. Aprobă normele, regulamentele, instrucțiunile și procedurile de lucru în │
│sistemul Arhivelor Naționale;
│
│6. Inițiază și coordonează activitatea de elaborare a actelor normative ce │
│reglementează organizarea și desfășurarea activității în domeniul
│
│arhivistic;
│
│7. Reprezintă Arhivele Naționale în relațiile cu autoritățile publice
│
│centrale și locale și cu persoanele fizice și juridice de drept public sau │
│privat;
│
│8. Coordonează, îndrumă și controlează activitatea de preluare, evidență,
│
│selecționare, păstrare, folosire și conservare a documentelor ce fac parte │
│din Fondul Arhivistic Național, deținute de structurile Arhivelor Naționale;│
│9. Coordonează, îndrumă și controlează activitatea de valorificare a
│
│informațiilor din documente, inițiază colaborări cu alte instituții de
│
│profil din țară și din străinătate și participă la activități cultural-
│
│științifice menite să asigure cunoașterea, folosirea și popularizarea
│
│documentelor din Fondul Arhivistic Național al României;
│
│10. Coordonează, îndrumă și controlează realizarea de către structurile
│
│Arhivelor Naționale a activităților de acordare a asistenței de specialitate│
│creatorilor și deținătorilor de documente;
│
│11. Stabilește politica de resurse umane și emite dispoziții privind:
│
│recrutarea, încadrarea, promovarea, încheierea, modificarea, suspendarea și │
│încetarea raporturilor de serviciu/contractelor individuale de muncă,
│
│formarea, perfecționarea pregătirii, evaluarea, motivarea, recompensarea,
│
│sancționarea personalului din subordine;
│
│12. Formulează propuneri sau dispune, după caz, în legătură cu stabilirea
│
│structurii de funcții și cu efectuarea de modificări în statele de
│
│organizare ale Arhivelor Naționale, în limita competențelor prevăzute de
│
│cadrul normativ aplicabil și a numărului de posturi aprobate;
│
│13. Stabilește obiectivele individuale și evaluează performanțele
│
│profesionale ale personalului de conducere din sistemul Arhivelor Naționale,│
│a căror activitate o coordonează în mod nemijlocit;
│
│14. Angajează și utilizează creditele bugetare numai în limita prevederilor │
│și destinațiilor aprobate, pentru cheltuieli strict legate de activitatea
│
│Arhivelor Naționale, cu respectarea prevederilor legale;
│
│15. Răspunde de execuția bugetului de venituri și cheltuieli al Arhivelor
│
│Naționale;
│
│16. Răspunde de angajarea, lichidarea și ordonanțarea cheltuielilor în
│
│limita creditelor bugetare repartizate și aprobate, pe baza unei bune
│
│gestiuni financiare;
│
│17. Răspunde de integritatea bunurilor încredințate instituției;
│
│18. Răspunde de organizarea și ținerea la zi a contabilității și
│
│prezentarea la termen a situațiilor financiare asupra situației
│
│patrimoniului aflat în administrare;
│
│19. Răspunde de organizarea sistemului de monitorizare a programului de
│
│achiziții publice și a programului de lucrări de investiții publice;
│
│20. Răspunde de organizarea evidenței programelor, inclusiv a
│
│indicatorilor aferenți acestora;
│
│21. Răspunde de organizarea și ținerea la zi a evidenței patrimoniului,
│
│conform prevederilor legale;
│
│22. Asigură securitatea și sănătatea lucrătorilor în toate aspectele legate │
│de muncă;
│
│ 23. Rezolvă personal lucrări arhivistice complexe și elaborează lucrări
│
│de analiză și sinteză solicitate de superiorii ierarhici;
│
│24. Îndeplinește următoarele obligații prevăzute de lege, pe linia
│
│protecției informațiilor clasificate:
│
│a) asigură înființarea și organizarea activității structurii de securitate, │
│respectiv nominalizarea șefului structurii de securitate, potrivit legii;
│
