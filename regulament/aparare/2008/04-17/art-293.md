# Articolul 293
(1) O structură flexibilă a NSE se realizează prin proiectarea din timp a unor module funcționale standardizate, capabile să îndeplinească toate funcționalitățile specifice.
(2) Structura generică prezintă două categorii de module funcționale:
a) module funcționale de management;
b) module funcționale de execuție.
