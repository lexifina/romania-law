# Articolul 8
Valoarea tranzacției
1. Valoarea unei tranzacții cu titluri de stat cu dobândă, încheiată pe baza prețului net introdus de trader în modulul de tranzacționare, se determină astfel:
┌ Preț_net (%) + Dobânda_acumulată (%) ┐
Valoare_tranzacție (lei) = │ ──────────────────────────────────── │ x Valoare_nominală (lei) x Nr._titluri
└ 100 ┘
2. Valoarea unei tranzacții cu titluri de stat cu dobândă, încheiată pe baza prețului brut introdus de trader în modulul de tranzacționare, se determină astfel:
┌ Preț_brut (%) ┐
Valoare_tranzacție (lei) = │ ───────────── │ x Valoare_nominală (lei) x Nr._titluri
└ 100 ┘
