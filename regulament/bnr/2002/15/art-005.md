# Articolul 5
Randament și preț
1. Relația dintre randamentul și prețul unui titlu de stat cu discont se determină astfel:
┌ ┐
│┌ 100 ┐ 365 │
Randament (%) = ││ ──────── - 1│ x ─────────────── │ x 100
│└ Preț (%) ┘ Nr._zile_rămase │
└ ┘
┌ 100 ┐
Preț (%) = │ ─────────────────────────────────────── │.
│ ┌ Randament (%) Nr._zile_rămase ┐ │
│ 1 + │ ───────────── x ─────────────── │ │
└ └ 100 365 ┘ ┘
în care:
-randament = randamentul anual exprimat procentual;
-preț = prețul exprimat ca procent din valoarea nominală;
-nr._zile_rămase = numărul de zile începând cu data decontării tranzacției inclusiv, până la data scadenței exclusiv.
2. În funcție de prospectul de emisiune, B.V.B. poate utiliza o altă convenție cu privire la numărul de zile corespunzătoare anului calendaristic.
