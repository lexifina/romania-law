Un API (application programming interface: interfață de programare
a  aplicației)  este  utilizat  pentru  a  transmite  bidirecțional  date  între
aplicațiile software într-un mod formalizat. Numeroase servicii oferă API-
uri publice, care permit oricui să trimită și să primească conținut din
serviciul  respectiv,  fără  costuri,  API-urile  care  funcționează  prin
intermediul internetului utilizând URL-uri de tip http://sunt denumite API-
uri web . Pe web, puteți trimite o solicitare către un API pentru a obține și
posta informații.
Toate aplicațiile favorite care se conectează la internet au la baza
API-uri. De exemplu, aplicațiile rețelelor de socializare utilizează API-uri
pentru a permite vizualizarea și publicarea de postări din aplicațiile lor
mobile.

apelează la protocoale de interoperabilitate care oferă un API standardizat

Susține că, aceasta procedură de integrare pe fiecare funcționalitate

Autoritatea contractantă, având în vedere principiile tratamentului

soluții. Din acest motiv, arata achizitoarea, se apeleaza la protocoale de
interoperabilitate care oferă un API standardizat care permite integrare
intre  diferite  soluții  fără  efort  și  costuri  suplimentare  de  dezvoltare.

proprietar ar duce în viitor la posibilitatea de a achiziționa servicii de
dezvoltare soft (costuri importante), lucru ce nu este nedorit, iar pe de alta
parte,  folosirea  unui  API  proprietar  permite  în  viitor  fenomenul  de
"captivitate" tehnologica astfel incat autoritatea contractanta sa fie nevoita
sa  solicite  anumite  cerințe  tehnice/parametri  tehnici  specifici  unui
producător/produs/tehnologie /marca. Având în vedere cele prezentate

mai  sus,  arata  autoritatea  contractanta,  se  înțelege  clar  ca  un  API
standardizat este un avantaj net pentru aceasta, asigurând dezvoltarea
viitoare a sistemului în vederea unor viitoare extinderi, adăugări de alte
soluții tip Smart City.
