# Articolul 34
În funcție de data la care are loc decontarea, pe piața secundară se pot încheia următoarele tipuri de tranzacții:
a) spot, pentru care data decontării este la două zile lucrătoare de la data tranzacției;
b) today, pentru care data decontării este aceeași cu data tranzacției;
c) tomorrow, pentru care data decontării este ziua lucrătoare următoare datei tranzacției;
d) forward, pentru care data decontării este o zi lucrătoare ulterioară decontării tranzacției spot.
