# Articolul 320
Cardul european contine urmatorul set obligatoriu de informații vizibile:
a) numele și prenumele asiguratului;
b) codul numeric personal al asiguratului;
c) data nasterii asiguratului;
d) data expirarii cardului;
e) codul Organizatiei Internationale pentru Standardizare pentru statul membru emitent al cardului;
f) numărul de identificare și acronimul casei de asigurări de sănătate care emite cardul;
g) numărul cardului.
