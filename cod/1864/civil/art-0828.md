# Articolul 828
Donatorul nu este responsabil de evicțiune către donatar pentru lucrurile dăruite.
Donatorul este responsabil de evicțiune când el a promis expres garanția.
Este asemenea responsabil când evicțiunea provine din faptul sau, când este în chestiune o donatiune care impune sarcini donatorului; într-acest caz însă, garanția este obligatorie numai până la suma sarcinilor.
