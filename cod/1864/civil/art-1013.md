# Articolul 1013
Candu obligațiunea este contractată sub condițiunea ca unu evenimentu n'are să se intemple, într'unu timpul defiptu, acesta condițiune este îndeplinită dacă timpulu a espiratu, fără ca evenimentulu nu se va mai intempla; dacă nu este timpul determinatu, condițiunea este îndeplinită numai candu va fi sicuru ca evenimentulu n'are să se mai intemple.
