# Articolul 1013
Când obligația este contractată sub condiția ca un eveniment n-are să se intample, într-un timp defipt, aceasta condiție este îndeplinită, dacă timpul a expirat, fără ca evenimentul să se fi întâmplat; este asemenea îndeplinită, dacă înaintea termenului este sigur ca evenimentul nu se va mai intampla; dacă nu este timp determinat, condiția este îndeplinită numai când va fi sigur ca evenimentul n-are să se mai intample.
