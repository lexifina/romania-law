# Articolul 1012
Când obligația este contractată sub condiția sa un eveniment oarecare se va intampla într-un timp fixat, condiția este considerată ca neîndeplinită, dacă timpul a expirat fără ca evenimentul să se intample.
Când timpul nu este fixat, condiția nu este considerată ca căzută, decât când este sigur ca evenimentul nu se va mai intampla.
