# Articolul 1012
CAndu obligațiunea este contractată, sub condițiunea de unu evenimentu ore'cari se va intempla într'unu timpul ficsatu, condițiunea este considerată ca neîndeplinită dacă timpulu a espiratu fără ca evenimentulu să se intemple.
Candu timpulu nu este ficsatu, condițiunea nu este considerată ca caduta, de cadu candu este siguru ca evenimentulu nu se va mai intempla.
