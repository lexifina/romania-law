# Articolul 1593
Depositulu este unu contractu esențiale gratuitu, cari nu poate ave de obiectul de catu lucruri mobili.
Elu nu este perfectu de catu candu s'a facutu traditiunea lucrului.
Traditiunea se inlocuesce prin singurulu consimtimentu, dacă lucrulu ce este a se lasă în depositu se afla deja în mana depositarului sub ori ce altu titlu.
