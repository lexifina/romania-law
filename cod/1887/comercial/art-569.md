# Articolul 569
În cas de deosebire între polițele aceleiași încărcări, face proba aceea ce se afla la căpitan, dacă este scrisă în întreg de către încărcător sau de către comisionarul seu; aceea ce este presintata de către încărcător sau de către persona căreia este adresată expedițiunea face proba, dacă este scrisă în întreg de căpitan.
