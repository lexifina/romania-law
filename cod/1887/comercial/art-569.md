# Articolul 569
În caz de deosebire între polițele aceleiași încărcări, face proba aceea ce se afla la căpitan, dacă este scrisă în întreg de către încărcător sau de către comisionarul sau; aceea ce este prezentată de către încărcător sau de către persoana căreia este adresată expedițiunea face proba, dacă este scrisă în întreg de căpitan.
