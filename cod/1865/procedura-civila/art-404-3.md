# Articolul 404^3
Dacă titlul executoriu emis de un alt organ decât o instanța judecătorească a fost desființat de acel organ sau de un alt organ din afara sistemului instanțelor judecătorești, iar modalitatea restabilirii situației anterioare executării nu este prevăzută de lege ori, deși este prevăzută, nu s-a luat această măsură, ea se va putea obține pe calea unei cereri introduse la instanța prevăzută de art. 404^2 alin. 3.
