# Articolul 404^3
Dacă titlul executoriu emis de un alt organ decat o instanța judecătorească a fost desfiintat de acel organ sau de un alt organ din afara sistemului instanțelor judecătorești, iar modalitatea restabilirii situației anterioare executarii nu este prevăzută de lege ori, desi este prevăzută, nu s-a luat această măsură, ea se va putea obtine pe calea unei cereri introduse la instanța prevăzută de art. 404^2 alin. 3.
