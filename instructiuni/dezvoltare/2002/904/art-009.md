# Articolul 9
Modelul abonamentului pentru beneficiarii Legii nr. 44/1994 este prezentat în anexa nr. 1, modelul tabelului nominal pentru eliberarea abonamentelor pentru beneficiarii Legii nr. 44/1994 este prezentat în anexa nr. 2, modelul situației centralizatoare lunare cuprinzând numărul de călători transportați este prezentat în anexa nr. 3, modelul formularului centralizator de decont este prezentat în anexa nr. 4.
