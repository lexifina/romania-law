# Articolul 1
(1) Modelul propunerii de candidatură care va fi utilizat la alegerile locale parțiale pentru primari din data de 11 iunie 2017 este prevăzut în anexa nr. 1.
(2) Modelul declarației de acceptare a candidaturii care va fi utilizat la alegerile locale parțiale pentru primari din data de 11 iunie 2017 este prevăzut în anexa nr. 2.
(3) Modelul declarației de renunțare la candidatură care va fi utilizat la alegerile locale parțiale pentru primari din data de 11 iunie 2017 este prevăzut în anexa nr. 3.
