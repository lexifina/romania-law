# Regulamentul de punere în aplicare (UE) 2018/1565 al Comisiei din 17 octombrie 2018 privind autorizarea unui preparat de endo-1,4-beta-mananază produsă de Paenibacillus lentus (DSM 28088) ca aditiv pentru hrana puilor pentru îngrășare, a puicuțelor pentru ouat și a speciilor minore de păsări de curte, altele decât păsările ouătoare, a curcanilor pentru îngrășare și a curcanilor crescuți pentru reproducere, a purceilor înțărcați, a porcilor pentru îngrășare și a speciilor minore de porcine (titularul autorizației: Elanco GmbH) (Text cu relevanță pentru SEE.)
