# Regulamentul de punere în aplicare (UE) 2023/1649 al Comisiei din 21 august 2023 de deschidere a unei anchete privind o eventuală circumvenție a măsurilor antidumping instituite prin Regulamentul de punere în aplicare (UE) 2021/1930 asupra importurilor de placaj din lemn de mesteacăn originar din Rusia, prin importuri de placaj din lemn de mesteacăn expediat din Turcia și Kazahstan, indiferent dacă a fost sau nu declarat ca fiind originar din Turcia și Kazahstan, și de supunere la înregistrare a importurilor de placaj din lemn de mesteacăn expediat din Turcia și Kazahstan
