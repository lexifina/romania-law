# Articolul 18
(1)
Autorizație zootehnică de funcționare a centrelor de colectare în format original pe hârtie, ștampilată ( Anexa nr. 6.3 .)
(2)
Durata de valabilitate a autorizației este nelimitată.
(3)
Evidența autorizațiilor emise se ține într-un registru special, al cărui model este prevăzut în ( Anexa nr. 6.4 .)
