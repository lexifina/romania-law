# Articolul 11
Punctajul pentru obținerea EDiR este calculat astfel: a)
punctajul ponderat scris = 70% din punctajul MRQs + 30% din punctajul SCs;
b)
punctajul evaluării clinice orientate = punctaj CORE;
c)
punctajul final pentru obținerea EDiR = media aritmetică dintre punctajul ponderat scris și punctajul evaluării clinice orientate.
