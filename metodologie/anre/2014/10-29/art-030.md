# Articolul 30
Pe baza modului de calcul prezentat la secțiunea 5, formula utilizată pentru actualizarea prețului de referință pentru energia termică produsă și livrată din centrale de cogenerare este: p(ref)^q,n = A^q x (p(comb)^n + f[CO(2)]^q x (1-f^alocaregratuita) + p(alte,var)^q x [1 + [I(inflatie)] /100]) + D^q x [1 + [I(inflatie)] / 100], (lei/MWh), unde: A^q = 100/eta^q (-) A^q - coeficientul aferent costurilor variabile ale energiei termice I(inflatie) - coeficientul de variație a inflației D^q = cf(alte)^q + i(sp)^q / [h(amortiz) x [f(inst)^q / 100] x h] (lei/MWh) D^q - coeficientul aferent costurilor fixe ale energiei termice.
