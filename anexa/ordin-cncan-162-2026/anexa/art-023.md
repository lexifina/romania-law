# Articolul 23
(1)
API trebuie efectuată în conformitate cu metodologii recunoscute pe plan internațional, aplicabile instalațiilor nucleare și ținând cont de specificul acestora.
(2)
API trebuie revizuită periodic, pe întreaga durată de viață a instalației nucleare, cel puțin o dată la fiecare 5 ani, sau ori de câte ori este necesar ca urmare a realizării de modificări în proiectul sau în funcționarea instalației nucleare cu implicații asupra nivelurilor și localizării pericolelor de incendiu, cu scopul de a reactualiza sau de a reconfirma măsurile de protecție la incendiu. Revizuirea și reactualizarea, respectiv reconfirmarea API trebuie efectuate în conformitate cu metodologii și proceduri specifice, aliniate la standardele, codurile și bunele practici recunoscute la nivel internațional și aprobate de către titularul de autorizație.
(3)
Revizia API trebuie să includă orice modificări ale instalației nucleare, ale amplasamentului și/sau modificări organizaționale, de la ultima revizie a analizei, care afectează sau ar putea afecta protecția la incendiu a instalației nucleare. Se includ modificările sistemelor de protecție la incendiu, modificările SSCE importante pentru securitatea nucleară și SSCE cu funcții în exploatarea fiabilă a instalației nucleare, modificările sarcinilor termice, modificările proceselor sau procedurilor, temporare ori permanente.
(4)
La proiectarea unei instalații nucleare noi, API se elaborează în scopul identificării cerințelor specifice de protecție la incendiu pentru diferitele zone. După finalizarea proiectului instalației nucleare, API trebuie revizuită și actualizată pentru a demonstra că funcțiile esențiale de securitate nucleară pot fi menținute în cazul tuturor incendiilor postulate.
(5)
Pentru instalațiile nucleare aflate în fazele de construcție și montaj, punere în funcțiune sau exploatare, pentru care API nu a fost elaborată în procesul de proiectare, trebuie elaborată o API prin care să se evalueze dacă măsurile de protecție la incendiu prevăzute sunt adecvate pentru a asigura menținerea funcțiilor esențiale de securitate nucleară. Dacă în urma acestei evaluări rezultă că aceste măsuri sunt insuficiente și/sau inadecvate, trebuie stabilite, în baza API, acțiunile corective și măsurile de îmbunătățire necesar a fi implementate.
