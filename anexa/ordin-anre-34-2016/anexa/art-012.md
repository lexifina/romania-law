# Articolul 12
Prețul de adjudecare pentru un anumit produs standard de capacitate va fi calculat în conformitate cu următoarea formulă:
P(A) = P(R) + AP,
unde: P(A) este prețul de adjudecare; P(R) este prețul de rezervă pentru un produs standard de capacitate care este în vigoare la data la care acest produs este licitat; AP este comisionul de licitație.
