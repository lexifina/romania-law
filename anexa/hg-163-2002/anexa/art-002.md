# Articolul 2
(1) Pentru alcool, băuturi alcoolice, vinuri și bere accizele datorate bugetului de stat sunt stabilite în suma fixa pe unitatea de măsura și sunt prevăzute în anexa nr. 1 la ordonanța de urgență.
(2) Sumele datorate bugetului de stat drept accize se determina după cum urmează:
a) pentru alcool etilic, distilate de origine agricolă și băuturi alcoolice distilate:
C
K x R A = ─── x ─────── x Q, 100
100
în care: C = concentrația alcoolică exprimată în procente de volum; K = acciza specifică prevăzută la nr. crt. 1 din anexa nr. 1 la ordonanța de urgență; R = cursul de schimb; Q = cantitatea (în litri);
b) pentru vinuri, băuturi fermentate (altele decât berea și vinul) și pentru produse intermediare:
K x R A = C x ─────── x Q, 100
în care: A = cuantumul accizei; C = numărul de grade alcoolice conținute; K = acciza unitară prevăzută la nr. crt. 2, 4 și 5 din anexa nr. 1 la ordonanța de urgență, în funcție de natura produsului; R = cursul de schimb; Q = cantitatea (în litri);
c) pentru bere:
K x R A = C x ─────── x Q, 100
în care: A = cuantumul accizei; C = numărul de grade Plato conținute; K = acciza unitară prevăzută la nr. crt. 3 din anexa nr. 1 la ordonanța de urgență, în funcție de capacitatea de producție anuală; R = cursul de schimb; Q = cantitatea (în litri).
(3) În anexa nr. 3 sunt redate exemple privind metodologia de calcul al accizelor.
