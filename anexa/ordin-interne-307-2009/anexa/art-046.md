# Articolul 46
Seria se compune din 3 părți:
a) prima parte este formată dintr-o literă (grup de litere) care arată componenta de specialitate;
b) partea a doua, formată din una sau două cifre, indică numărul postului din cadrul componentei de specialitate;
c) partea a treia este formată din una sau două cifre și arată schimbul și ordinea intrării în serviciu. Cifrele impare (1, 3, 5...) indică schimbul 1, iar cifrele pare (2, 4, 6....) indică schimbul 2.
