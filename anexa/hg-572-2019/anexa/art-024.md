# Articolul 24
(1)
Tricoul cu mânecă lungă se confecționează, atât pentru bărbați, cât și pentru femei, din țesătură bumbac, de culoare bleumarin. Acesta este prevăzut cu guler, epoleți și este inscripționat pe spate și pe piept cu sintagma VAMA-CUSTOMS-DOUANE.
(2)
Tricoul cu mânecă lungă utilizat de către personalul vamal din structurile de echipe canine și control nedistructiv se confecționează din țesătură bumbac, de culoare neagră. Acesta este prevăzut cu guler, epoleți și este inscripționat pe spate și pe piept cu sintagma VAMA-CUSTOMS-DOUANE.
(3)
Tricoul cu mânecă lungă se poartă la uniforma de control.
