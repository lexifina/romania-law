# Articolul 2
(1) Proiectul monografiei cuprinde principalele date și informații referitoare la:
a) istoria și geografia unității administrativ-teritoriale, memoriu, ca parte introductivă a monografiei;
b) structura demografică și fondul de locuințe, conform machetelor al căror model este prevăzut în anexele nr. 1a), 1b) și 1c);
c) rețeaua hidrografică, conform machetelor al căror model este prevăzut în anexele nr. 2a), 2b), 2c) și 2d);
d) sursele de apă potabilă și industrială, conform machetei al cărei model este prevăzut în anexa nr. 3;
e) fondul forestier, conform machetei al cărei model este prevăzut în anexa nr. 4;
f) rețelele rutiere, conform machetei al cărei model este prevăzut în anexa nr. 5;
g) rețelele de cale ferată, conform machetei al cărei model este prevăzut în anexa nr. 6;
h) lucrările de artă, conform machetei al cărei model este prevăzut în anexa nr. 7;
i) rețelele de comunicații, conform machetelor al căror model este prevăzut în anexele nr. 8a), 8b), 8c), 8d) și 8e);
j) rețelele de energie electrică, conform machetei al cărei model este prevăzut în anexa nr. 9;
k) operatorii economici, conform machetei al cărei model este prevăzut în anexa nr. 10;
l) spațiile de depozitare, conform machetei al cărei model este prevăzut în anexa nr. 11;
m) unitățile de cazare și alimentație publică, conform machetei al cărei model este prevăzut în anexa nr. 12;
n) instalațiile de transport pe cablu, conform machetei al cărei model este prevăzut în anexa nr. 13;
o) unitățile de asistență medicală, conform machetei al cărei model este prevăzut în anexa nr. 14;
p) conductele magistrale de transport, conform machetelor al căror model este prevăzut în anexele nr. 15a) și 15b);
q) mijloacele de transport și utilajele de construcții, conform machetei al cărei model este prevăzut în anexa nr. 16;
r) aeroporturile și porturile, conform machetelor al căror model este prevăzut în anexele nr. 17a), 17b) și 17c);
s) instituțiile de învățământ, conform machetei al cărei model este prevăzut în anexa nr. 18;
ș) editurile și tipografiile, conform machetei al cărei model este prevăzut în anexa nr. 19;
t) fondul de adăpostire și sistemul forțelor de protecție în situații de urgență, conform machetelor al căror model este prevăzut în anexele nr. 20a) și 20b).
(2) În cadrul proiectului monografiei, se atașează hărțile întocmite la scara 1: 100000, ultima ediție, astfel:
a) harta nr. 1 pentru anexele nr. 2a)-2d);
b) harta nr. 2 pentru anexele nr. 3 și 11;
c) harta nr. 3 pentru anexa nr. 4;
d) harta nr. 4 pentru anexele nr. 5, 6 și 7;
e) harta nr. 5 pentru anexa nr. 8c).
