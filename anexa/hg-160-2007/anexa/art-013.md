# Articolul 13
(1) Cămașa cu mânecă lungă, al cărei model este prevăzut în anexa nr. 4, este de culoare bleu, croită drept, având mânecile prevăzute cu manșete care se închid cu nasturi confecționați din plastic, de format mic.
(2) Cămașa cu mânecă lungă se confecționează din tercot și se poartă numai cu cravată și cu veston sau cu bluzon. În ocazii speciale cămașa poate avea culoarea albă.
