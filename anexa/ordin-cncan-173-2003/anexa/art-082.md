# Articolul 82
Pentru estimarea dozei efective când se poartă două dozimetre, unul sub șorțul de protecție și celălalt deasupra șorțului de protecție, se poate utiliza următoarea formulă:
Doza efectivă (estimată) = 0,5 DT + 0,025 DG, unde: - DT este doza la nivelul taliei sub șorț;
- DG este doza la nivelul gâtului deasupra șorțului.
