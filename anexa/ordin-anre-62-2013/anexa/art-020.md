# Articolul 20
(1)
Constatarea contravențiilor și aplicarea sancțiunilor se realizează prin proces-verbal de constatare și sancționare a contravențiilor, încheiat de o persoană împuternicită în acest sens de către președintele ANRE, denumită generic agent constatator.
(2)
Calitatea de agent constatator este atestată prin legitimație, al cărei model este prevăzut în anexa nr. 2 .
