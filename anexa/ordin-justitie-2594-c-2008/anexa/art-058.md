# Articolul 58
(1)
Emblema este un element complementar și facultativ pentru identificarea și individualizarea comerciantului, deosebind un comerț de alt comerț de același fel.
(2)
Emblema poate fi: - reprezentată prin cuvinte -- când constă într-o denumire;
- reprezentată figurativ - când constă într-o reprezentare grafică;
- complexă - când este alcătuită din combinarea cuvintelor cu elemente figurative.
(3)
Emblema trebuie să se deosebească de emblemele înscrise în registrul comerțului.
