# Articolul 25
Autorizatiile și licentele se înregistrează într-un registru în care înscrierea se face în ordinea emiterii acestor acte de reglementare. Numărul autorizatiei/licentei este numărul de ordine din acest registru. Registrul este public și poate fi consultat de către cei interesati la sediul autorității competente, conform unui program care va fi afisat.
