# Articolul 17
Deținătorul autorizației de import paralel trebuie să informeze Institutul pentru Controlul Produselor Biologice și Medicamentelor de uz Veterinar cu privire la orice modificare a datelor din autorizația de import paralel și/sau a datelor din documentele depuse odată cu cererea de obținere a autorizației de import paralel.
