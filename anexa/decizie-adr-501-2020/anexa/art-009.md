# Articolul 9
Pentru accesarea în bune condiții a site-ului www.e-licitatie.ro este necesar să se dispună de un sistem cu următoarele configurații minime: - cerințe software: browsere: Chrome 49.0.2623, Firefox 45.0, IE 10 sau versiuni ulterioare ale acestora;
- alte produse software instalate;
- Java Runtime Environment (JRE) - versiune minimă 1.7;
- utilitar de vizualizare fișiere PDF;
- utilitar de vizualizare fișiere semnate;
- aplicație locală pentru semnarea fișierelor;
- rezoluția grafică minimă: 1280 x 720.
