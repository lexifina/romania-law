# Articolul 6
Transferul de expertiză
Transferul de expertiză către statele partenere ale României se realizează prin intermediul unor misiuni temporare, la care pot participa, dacă au calificarea necesară pentru îndeplinirea misiunii respective: a)
persoane din instituțiile publice din România;
b)
persoane din instituțiile publice din state beneficiare;
c)
persoane din entități private și din mediul asociativ neguvernamental din România;
d)
persoane din entități private și din mediul asociativ neguvernamental din state beneficiare.
