(1) Pe baza modului de calcul prezentat în cap. VII, formula utilizată pentru ajustarea bonusului de referință, corespunzătoare anului n de aplicare a schemei de sprijin, este:
B^n(ref) = A * (p^n(comb) + p^n(CO2) * f(CO2) + p^cog(alte,var) * [1 +
+ I(inflație)/100]) - B * P(ref)^q,n - C * (n-1)* [1 + (Iinflație)/100] +
+ D * [1 + I(inflație)/100] - P^n(PZU) (lei/MWh),
unde: E(l) + Q A = coeficientul aferent costurilor variabile, A = ------------------- (-); (Eta(net)/100) * E(l)
Q B = coeficientul aferent veniturilor energiei termice, B = ----- (-); E(l)
C = coeficientul de reducere a bazei reglementate a activelor, datorată amortizării activelor,
i(sp)^cog * P(e) C = -------------------------------- * r (lei/MWh); E(l) * f(inst)^e * h(amort)^cog
D = coeficientul aferent costurilor fixe, D = D(1) + D(2) + D(3) (lei/MWh), alcătuit din:
D(1) = coeficientul costurilor cu operarea și mentenanța,
E(l) +Q D(1) = cf(alte)^cog * -------- (lei/MWh); E(l)
D(2) = coeficientul bazei reglementate a activelor, aferentă investiției inițiale,
r * i(sp)^cog * P(e) D(2) = --------------------- (lei/MWh) f^e(inst) * E(l)
D(3) = coeficientul amortizării anuale,
i(sp)^cog * P(e) D(3) = -------------------------------------- (lei/MWh). h(amort)^cog * (f^e(inst)/100) * E(l)
