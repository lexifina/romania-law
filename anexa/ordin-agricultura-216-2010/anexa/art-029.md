# Articolul 29
Controlul ex-post poate fi suspendat dacă: a)
obținerea dovezilor de către echipa de control nu este posibilă în termenul stabilit cu întreprinderea, până la obținerea acestora, cu excepția adreselor din străinătate;
b)
controlul este extins la terți, până la finalizarea acestuia;
c)
este necesară obținerea informațiilor de la alte state membre, până la obținerea acestora;
d)
este necesară obținerea informațiilor din țări terțe, până la obținerea acestora.
